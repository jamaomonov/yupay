# GA4: воронка покупки (GTM + GA4)

Сайт (`apps/web`) кладёт в `window.dataLayer` события воронки в формате GA4
(`apps/web/src/lib/analytics-events.ts`). Чтобы они дошли до GA4, в контейнере
GTM `GTM-5B7J6XCB` нужен **один** новый тег. Код больше ничего не требует.

| Событие            | Когда                                                          | Параметры                        |
| ------------------ | -------------------------------------------------------------- | -------------------------------- |
| `view_item_list`   | открыт каталог `/store` (или категория `?cat=`)                | список брендов (до 50)           |
| `view_item`        | открыта страница бренда                                        | бренд                            |
| `select_item`      | выбран номинал                                                 | SKU, цена в UZS                  |
| `player_check`     | проверка ID игрока завершилась                                 | `result`, `item_brand`           |
| `begin_checkout`   | заказ создан                                                   | сумма, валюта, позиции           |
| `add_payment_info` | платёж запущен                                                 | `payment_type` (click, payme, …) |
| `purchase`         | заказ оплачен (страница заказа) — **уже настроен**, не трогать | —                                |

Персональных данных в событиях нет: ни email, ни ID игрока, ни ника, ни трейд-ссылки.

## (а) GTM — один тег на все события

В контейнере уже есть Google-тег GA4 (`G-0Z061SVQ11`) и отдельный тег `purchase`
(версия 2 «GA4 + Ads purchase»). `purchase` в новый тег **не добавлять** — иначе
покупки посчитаются дважды.

1. tagmanager.google.com → контейнер `GTM-5B7J6XCB` → **Переменные** →
   «Встроенные переменные» → **Настроить** → включить **Event**.
2. **Переменные** → «Пользовательские» → **Создать** три раза, тип
   «Переменная уровня данных» (Data Layer Variable), версия 2:
   - `DLV - payment_type` → имя `ecommerce.payment_type`;
   - `DLV - result` → имя `result`;
   - `DLV - item_brand` → имя `item_brand`.
3. **Триггеры** → **Создать** → «Пользовательское событие» (Custom Event):
   - Имя события: `^(view_item_list|view_item|select_item|player_check|begin_checkout|add_payment_info)$`
   - галочка **Использовать регулярные выражения**;
   - «Все специальные события». Название: `CE - GA4 funnel`.
4. **Теги** → **Создать** → «Google Analytics: событие GA4»:
   - Идентификатор (Measurement ID): `G-0Z061SVQ11` — тот же, что у тега `purchase`;
   - Название события: `{{Event}}`;
   - **Параметры события**: `payment_type` = `{{DLV - payment_type}}`,
     `result` = `{{DLV - result}}`, `item_brand` = `{{DLV - item_brand}}`;
   - **Другие настройки → Электронная торговля → Отправлять данные электронной
     торговли**, источник **Уровень данных** (Data Layer);
   - если у тега `purchase` в параметрах стоит `page_location` = переменная из
     уровня данных — поставить так же (адрес без `?email=`);
   - триггер `CE - GA4 funnel`. Название: `GA4 - funnel events`.
5. **Предварительный просмотр** → открыть `https://yupay.uz/ru/store` → в Tag
   Assistant видно `view_item_list` и тег «Сработал». Дальше: страница бренда
   (`view_item`), выбрать номинал (`select_item`), проверить ID (`player_check`),
   оплатить до перехода в банк (`begin_checkout`, `add_payment_info`). Платить не
   нужно — неоплаченный заказ отменится сам. В GA4 → Администратор →
   **DebugView** события видны с параметрами.
6. **Отправить** → название версии «GA4 funnel» → **Опубликовать**.

## (б) GA4 — отчёт по воронке

1. GA4 → Администратор → **Пользовательские определения** → **Создать
   параметр** дважды, область «Событие»: `payment_type` и `result` (имя
   параметра = имя). `item_brand` уже есть стандартный («Бренд товара»).
2. **Исследования** → «Последовательность» (Funnel exploration) → шаги:
   `view_item` → `select_item` → `begin_checkout` → `add_payment_info` → `purchase`.
   Разбивка: «Бренд товара», потом `payment_type`. Открытая воронка — да.
3. Необязательно: Администратор → **Ключевые события** → отметить
   `begin_checkout` и `add_payment_info`. `purchase` уже ключевое — Ads-конверсию
   не менять.

Пользовательские параметры появляются в отчётах через ~24 ч после первого события.
