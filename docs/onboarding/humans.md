# Onboarding for humans

Welcome to YuPay. Read this and `AGENTS.md` in full before touching code.

## Day 1

1. Read `AGENTS.md`. All of it. It is **not** boilerplate.
2. Read `docs/architecture/overview.md` and `docs/architecture/module-map.md`.
3. Skim every ADR in `docs/decisions/`.
4. Follow `docs/onboarding/local-setup.md` to get the stack running locally.
5. Pick a "good first issue" labelled `onboarding`.

## Day 2

1. Read the relevant `docs/runbooks/` for the area you'll work on.
2. Pair with someone on your first PR.

## Communication

- `#yupay-dev` (Telegram) — engineering chat.
- `#yupay-ops` (Telegram) — incidents, deploys, alerts.
- Async standups in `#yupay-standup` (Telegram), Mon/Wed/Fri.
