# P2P Deposit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reseller tops up their USD deposit in the cabinet by transferring an exact,
reserved soʻm amount to the owner's Humo card. The deposit is credited automatically
when @HUMOcardbot's notification reaches our Telegram Business bot.

**Architecture:**

- New API module `yupay.modules.p2p` owns three tables: cards, reservations
  (exact-amount holds, uniqueness enforced by a partial unique index) and the
  incoming-transfer journal, plus a single-row settings table.
- Telegram delivers `business_message` updates to `POST /api/v1/webhooks/telegram/p2p`.
  The handler verifies the secret header before parsing, files the notification in the
  journal and matches it to a reservation.
- Matching credits `merchants.deposit.credit_deposit` in one transaction.
- Two scheduler jobs expire reservations, end quarantine and alert on silence.
- The cabinet (Next.js) and the admin SPA get their screens.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 async, Alembic, pytest +
testcontainers, hypothesis; Next.js 15 (apps/merchant), Vite + React 19 (apps/admin),
Vitest; next-intl catalogs in `packages/i18n`.

**Spec:** `docs/superpowers/specs/2026-10-04-p2p-deposit-design.md` — read it before
any task.

## Global Constraints

- Reservation lifetime **exactly 5 minutes** (`RESERVATION_TTL = timedelta(minutes=5)`).
  A transfer whose bank time is after `expires_at` is never credited automatically.
- Quarantine **10 minutes** after expiry or cancel (`QUARANTINE = timedelta(minutes=10)`).
  A paid reservation releases its amount immediately.
- Exact amount: whole soʻm, try `amount`, `amount+1` … `amount+99`. Past that,
  `ServiceUnavailableError` (503).
- Per-card defaults: `min_amount_uzs = 10000`, `max_amount_uzs = 10000000`,
  `daily_limit_uzs = NULL` (off). All are editable in the admin.
- One `pending` reservation per merchant at a time.
- Rate: `pricing.fx_guard.guarded_usd_rate(db, quote="UZS")`, frozen on the reservation.
  `amount_usd = (amount_uzs / rate)` quantized to `0.01` with **ROUND_DOWN**, so we
  never credit more than was paid.
- Money: `Decimal` only. Never float.
- The webhook verifies `X-Telegram-Bot-Api-Secret-Token` with `hmac.compare_digest`
  **before** reading the body. It fails closed when the secret is unset.
- **Accept only** `business_message` where `from.id == settings.humo_bot_user_id`, no
  `forward_origin`, and `chat.id == from.id`. Every other update is answered 200 and
  dropped.
- Never log: the full card number, the holder's name, raw notification text, or any
  Telegram user id other than as a count. Log reservation number, amount, card last4.
- Every state-changing cabinet and admin endpoint accepts `Idempotency-Key` (AGENTS.md
  §9).
- The ops alert channel is `yupay.modules.notifications.alerts.send_admin_alert(text,
kind=...)`, called **after** commit and never inside the money transaction.
- i18n: every new key goes in `packages/i18n/locales/{ru,en,uz}/*.json` in the same
  task.
- Commit messages: Conventional Commits, scope `api/p2p`, `merchant/p2p`,
  `admin/p2p`, `docs/p2p`; end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never push or deploy without an explicit owner command.

## Review Focus

1. **Two notifications for the same exact amount within seconds**, the second an
   unrelated transfer. Exactly one credit; the second row is `unmatched`. Test in
   Task 4.
2. **Webhook delivered late** (Telegram retried after downtime). The sweep has already
   marked the reservation `expired`, but the bank time is inside the 5 minutes. It must
   still match. Test in Task 4.
3. **Two cabinet requests for the same amount at the same instant** (two resellers).
   They must get different amounts, with no 500. Test in Task 3 (concurrent sessions).
4. **A credit with tiyin** (`54.728,28`) or for another card's last4 must never match,
   even if a reservation for `54 728` exists. Test in Task 4.
5. **Cancel racing a matching webhook.** Whichever commits first wins. A cancelled
   reservation is never credited, and a paid one cannot be cancelled (409). Test in
   Tasks 3/4 via the row lock.

"""Read a @HUMOcardbot notification into numbers (spec §3).

Pure: no I/O, no clock. A line we do not recognise makes the whole message
``unparsed`` rather than half-read — a guessed amount is worse than none,
because a guessed amount can match a reservation.
"""

from __future__ import annotations

import re
from datetime import datetime
from decimal import Decimal
from typing import Literal
from zoneinfo import ZoneInfo

from pydantic import BaseModel, ConfigDict

TASHKENT = ZoneInfo("Asia/Tashkent")

_AMOUNT = r"(\d{1,3}(?:\.\d{3})*,\d{2})\s*UZS"
_SIGNED = re.compile(rf"^\s*(➕|➖)\s*{_AMOUNT}\s*$", re.M)
_BALANCE = re.compile(rf"^\s*💰\s*{_AMOUNT}\s*$", re.M)
_SOURCE = re.compile(r"^\s*📍\s*(.+?)\s*$", re.M)
_CARD = re.compile(r"\*(\d{4})\b")
_TIME = re.compile(r"(\d{2}):(\d{2})\s+(\d{2})\.(\d{2})\.(\d{4})")


class ParsedNotification(BaseModel):
    """One notification, read. Every field is ``None`` when ``kind`` is ``unparsed``."""

    model_config = ConfigDict(frozen=True)

    kind: Literal["credit", "debit", "unparsed"]
    amount: Decimal | None = None
    source: str | None = None
    card_last4: str | None = None
    bank_time: datetime | None = None
    balance_after: Decimal | None = None


_UNPARSED = ParsedNotification(kind="unparsed")


def _money(raw: str) -> Decimal:
    return Decimal(raw.replace(".", "").replace(",", "."))


def parse_humo(text: str) -> ParsedNotification:
    """Parse one notification.

    Args:
        text: The message text exactly as Telegram delivered it.

    Returns:
        A credit or debit with every field set, or ``unparsed``.
    """
    signed = _SIGNED.search(text or "")
    balance = _BALANCE.search(text or "")
    card = _CARD.search(text or "")
    when = _TIME.search(text or "")
    source = _SOURCE.search(text or "")
    if not (signed and balance and card and when):
        return _UNPARSED
    hh, mm, dd, mo, yyyy = (int(g) for g in when.groups())
    try:
        bank_time = datetime(yyyy, mo, dd, hh, mm, tzinfo=TASHKENT)
    except ValueError:
        return _UNPARSED
    return ParsedNotification(
        kind="credit" if signed.group(1) == "➕" else "debit",
        amount=_money(signed.group(2)),
        source=source.group(1) if source else None,
        card_last4=card.group(1),
        bank_time=bank_time,
        balance_after=_money(balance.group(1)),
    )


__all__ = ["TASHKENT", "ParsedNotification", "parse_humo"]
```

"""Short public number for a top-up reservation: ``T`` + 7 Crockford characters.

Random, not sequential — a sequence would tell anyone holding two numbers how
many top-ups happened in between. 32^7 ≈ 3.4·10^10; the unique index catches
the collision this makes vanishingly rare, and the caller retries.
"""

from __future__ import annotations

import secrets
from typing import Final

ALPHABET: Final = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"


def new_reservation_number() -> str:
    """A fresh ``T…`` number."""
    return "T" + "".join(secrets.choice(ALPHABET) for _ in range(7))


__all__ = ["ALPHABET", "new_reservation_number"]
```

"""P2P card transfers: cards, exact-amount reservations, the incoming journal (spec §5.2)."""

from __future__ import annotations

from datetime import datetime
from decimal import Decimal

from sqlalchemy import (
    BigInteger, Boolean, CheckConstraint, DateTime, ForeignKey, Index, Integer,
    LargeBinary, Numeric, String, Text, UniqueConstraint, text,
)
from sqlalchemy.dialects.postgresql import ARRAY, UUID
from sqlalchemy.orm import Mapped, mapped_column

from yupay.core.db import Base


class P2PCard(Base):
    """A card resellers transfer to. ``pan_*`` is the sealed full number."""

    __tablename__ = "p2p_cards"

    id: Mapped[str] = mapped_column(UUID(as_uuid=False), primary_key=True)
    label: Mapped[str] = mapped_column(String(64), nullable=False)
    pan_ciphertext: Mapped[bytes] = mapped_column(LargeBinary, nullable=False)
    pan_nonce: Mapped[bytes] = mapped_column(LargeBinary, nullable=False)
    pan_last4: Mapped[str] = mapped_column(String(4), nullable=False)
    holder_name: Mapped[str] = mapped_column(String(128), nullable=False)
    network: Mapped[str] = mapped_column(String(16), nullable=False)
    active: Mapped[bool] = mapped_column(Boolean, nullable=False, server_default=text("true"))
    min_amount_uzs: Mapped[int] = mapped_column(Integer, nullable=False, server_default="10000")
    max_amount_uzs: Mapped[int] = mapped_column(Integer, nullable=False, server_default="10000000")
    daily_limit_uzs: Mapped[int | None] = mapped_column(BigInteger, nullable=True)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=text("CURRENT_TIMESTAMP")
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=text("CURRENT_TIMESTAMP")
    )
    updated_by: Mapped[str | None] = mapped_column(UUID(as_uuid=False), nullable=True)

    __table_args__ = (
        CheckConstraint("network IN ('humo','uzcard')", name="ck_p2p_cards_network"),
        CheckConstraint("min_amount_uzs > 0 AND max_amount_uzs >= min_amount_uzs",
                        name="ck_p2p_cards_bounds"),
    )


class P2PReservation(Base):
    """An exact amount held on a card for one reseller for five minutes."""

    __tablename__ = "p2p_reservations"

    id: Mapped[str] = mapped_column(UUID(as_uuid=False), primary_key=True)
    number: Mapped[str] = mapped_column(String(8), nullable=False, unique=True)
    card_id: Mapped[str] = mapped_column(UUID(as_uuid=False), ForeignKey("p2p_cards.id"), nullable=False)
    amount_uzs: Mapped[int] = mapped_column(BigInteger, nullable=False)
    purpose: Mapped[str] = mapped_column(String(24), nullable=False)
    merchant_id: Mapped[str | None] = mapped_column(
        UUID(as_uuid=False), ForeignKey("merchants.id"), nullable=True
    )
    fx_rate: Mapped[Decimal] = mapped_column(Numeric(18, 6), nullable=False)
    fx_snapshot_id: Mapped[str | None] = mapped_column(UUID(as_uuid=False), nullable=True)
    amount_usd: Mapped[Decimal] = mapped_column(Numeric(18, 2), nullable=False)
    status: Mapped[str] = mapped_column(String(16), nullable=False, server_default="pending")
    holds_amount: Mapped[bool] = mapped_column(Boolean, nullable=False, server_default=text("true"))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), nullable=False)
    expires_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), nullable=False)
    closed_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    quarantine_until: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    incoming_id: Mapped[str | None] = mapped_column(UUID(as_uuid=False), nullable=True)
    idempotency_key: Mapped[str | None] = mapped_column(String(128), nullable=True)

    __table_args__ = (
        CheckConstraint("status IN ('pending','paid','expired','cancelled')",
                        name="ck_p2p_reservations_status"),
        CheckConstraint("purpose IN ('merchant_deposit')", name="ck_p2p_reservations_purpose"),
        CheckConstraint("amount_uzs > 0", name="ck_p2p_reservations_amount"),
        # The rule the whole design rests on: one open amount per card.

              postgresql_where=text("holds_amount")),
        Index("uq_p2p_reservations_one_pending", "merchant_id", unique=True,
              postgresql_where=text("status = 'pending'")),
        Index("uq_p2p_reservations_idem", "merchant_id", "idempotency_key", unique=True,
              postgresql_where=text("idempotency_key IS NOT NULL")),
        Index("ix_p2p_reservations_sweep", "status", "expires_at"),
    )

    expired: int
    released: int


def expire_in_place(r: P2PReservation, now_: datetime) -> None:
    """Close a pending reservation past its five minutes; quarantine starts now."""
    r.status = "expired"
    r.closed_at = r.expires_at
    r.quarantine_until = r.expires_at + QUARANTINE


async def _matched_today(db: AsyncSession, card: P2PCard, now_: datetime) -> int:
    start = datetime.combine(now_.astimezone(TASHKENT).date(), time(), TASHKENT)
    total = await db.scalar(
        select(func.coalesce(func.sum(P2PReservation.amount_uzs), 0)).where(
            P2PReservation.card_id == card.id,
            P2PReservation.status == "paid",
            P2PReservation.closed_at >= start,
        )
    )
    return int(total or 0)


async def _pick_card(db: AsyncSession, amount: int, now_: datetime) -> P2PCard:
    cards = (await db.execute(
        select(P2PCard).where(
            P2PCard.active.is_(True),
            P2PCard.min_amount_uzs <= amount,
            P2PCard.max_amount_uzs >= amount + MAX_BUMP,
        )
    )).scalars().all()
    best: tuple[int, P2PCard] | None = None
    for card in cards:
        room = None
        if card.daily_limit_uzs is not None:
            room = card.daily_limit_uzs - await _matched_today(db, card, now_)
            if room < amount + MAX_BUMP:
                continue
        score = room if room is not None else 10**18
        if best is None or score > best[0]:
            best = (score, card)
    if best is None:
        raise ConflictError("no card can take this amount", code="p2p_no_card")
    return best[1]


async def _snapshot_id(db: AsyncSession, rate: Decimal) -> str | None:
    """The ``fx_snapshots`` row behind the guarded rate (orders.service precedent)."""
    return await db.scalar(
        select(FxSnapshot.id)
        .where(FxSnapshot.base == "USD", FxSnapshot.quote == "UZS", FxSnapshot.rate == rate)
        .order_by(FxSnapshot.created_at.desc())
        .limit(1)
    )


async def reserve(
    db: AsyncSession, *, merchant_id: str, amount_uzs: int, idempotency_key: str | None
) -> P2PReservation:
    """Hold an exact amount for five minutes. See the module docstring."""
    if idempotency_key is not None:
        prior = await db.scalar(select(P2PReservation).where(
            P2PReservation.merchant_id == merchant_id,
            P2PReservation.idempotency_key == idempotency_key,
        ))
        if prior is not None:
            return prior
    if not admits(await load_settings(db), merchant_id):
        raise NotFoundError("p2p top-up is not enabled", code="p2p_disabled")
    open_one = await db.scalar(select(P2PReservation).where(
        P2PReservation.merchant_id == merchant_id, P2PReservation.status == "pending"
    ))
    now_ = now()
    if open_one is not None and open_one.expires_at <= now_:
        expire_in_place(open_one, now_)
        await db.flush()
        open_one = None
    if open_one is not None:
        raise ConflictError("a top-up is already waiting", code="p2p_reservation_open",
                            number=open_one.number)
    card = await _pick_card(db, amount_uzs, now_)
    try:
        rate = await guarded_usd_rate(db, quote="UZS")
    except RateRejected as exc:
        raise ServiceUnavailableError("rate unavailable", code="fx_unavailable") from exc
    snapshot_id = await _snapshot_id(db, rate)

    for bump in range(MAX_BUMP + 1):
        amount = amount_uzs + bump
        row = P2PReservation(
            id=new_id(), number=new_reservation_number(), card_id=card.id,
            amount_uzs=amount, purpose="merchant_deposit", merchant_id=merchant_id,
            fx_rate=rate, fx_snapshot_id=snapshot_id,
            amount_usd=(Decimal(amount) / rate).quantize(_CENT, rounding=ROUND_DOWN),
            status="pending", holds_amount=True, created_at=now_,
            expires_at=now_ + RESERVATION_TTL, idempotency_key=idempotency_key,
        )
        try:
            async with db.begin_nested():
                db.add(row)
                await db.flush()
        except IntegrityError as exc:
            name = str(getattr(exc.orig, "constraint_name", "") or exc)
            if "uq_p2p_reservations_open_amount" in name:
                continue
            raise  # one_pending / idem races surface; the route maps them
        log.info("p2p.reserved", number=row.number, amount_uzs=amount, card_last4=card.pan_last4)
        return row
    raise ServiceUnavailableError("every nearby amount is held", code="p2p_amount_busy")


async def _own(db: AsyncSession, merchant_id: str, number: str, *, lock: bool) -> P2PReservation:
    stmt = select(P2PReservation).where(
        P2PReservation.number == number, P2PReservation.merchant_id == merchant_id
    )
    if lock:
        stmt = stmt.with_for_update()
    row = await db.scalar(stmt)
    if row is None:
        raise NotFoundError("top-up not found", code="p2p_not_found")
    return row


async def cancel(db: AsyncSession, *, merchant_id: str, number: str) -> P2PReservation:
    """Release a pending reservation; its amount stays quarantined (D3)."""
    r = await _own(db, merchant_id, number, lock=True)
    now_ = now()
    if r.status == "pending" and r.expires_at <= now_:
        expire_in_place(r, now_)
    if r.status == "cancelled":
        return r
    if r.status != "pending":
        raise ConflictError("this top-up can no longer be cancelled", code="p2p_not_cancellable")
    r.status, r.closed_at, r.quarantine_until = "cancelled", now_, now_ + QUARANTINE
    await db.flush()
    log.info("p2p.cancelled", number=r.number)
    return r


async def read(db: AsyncSession, *, merchant_id: str, number: str) -> P2PReservation:
    """One reservation; a stale ``pending`` is reported (and stored) as expired."""
    r = await _own(db, merchant_id, number, lock=False)
    if r.status == "pending" and r.expires_at <= now():
        expire_in_place(r, now())
        await db.flush()
    return r


async def list_for_merchant(
    db: AsyncSession, *, merchant_id: str, limit: int, cursor: str | None
) -> tuple[list[P2PReservation], str | None]:
    """Newest first, keyset on ``(created_at, id)`` (merchants.transactions shape)."""
    stmt = select(P2PReservation).where(P2PReservation.merchant_id == merchant_id)
    if cursor:
        at, rid = transactions.decode_cursor(cursor)
        stmt = stmt.where((P2PReservation.created_at < at)
                          | ((P2PReservation.created_at == at) & (P2PReservation.id < rid)))
    rows = list((await db.execute(
        stmt.order_by(P2PReservation.created_at.desc(), P2PReservation.id.desc()).limit(limit + 1)
    )).scalars().all())
    page = rows[:limit]
    nxt = transactions.encode_cursor(page[-1].created_at, page[-1].id) if len(rows) > limit else None
    return page, nxt


async def sweep(db: AsyncSession, *, now_: datetime) -> SweepResult:
    """Expire overdue pending rows, then release amounts whose quarantine ended."""
    expired = await db.execute(
        update(P2PReservation)
        .where(P2PReservation.status == "pending", P2PReservation.expires_at <= now_)
        .values(status="expired", closed_at=P2PReservation.expires_at,
                quarantine_until=P2PReservation.expires_at + QUARANTINE)
    )
    released = await db.execute(
        update(P2PReservation)
        .where(P2PReservation.holds_amount.is_(True),
               P2PReservation.status.in_(("expired", "cancelled")),
               P2PReservation.quarantine_until <= now_)
        .values(holds_amount=False)
    )
    return SweepResult(expired=expired.rowcount or 0, released=released.rowcount or 0)

           "expire_in_place", "list_for_merchant", "read", "reserve", "sweep"]

```python
"""File a @HUMOcardbot notification and, if it pays a reservation, credit it (spec §5.4–5.5).

One transaction, owned by the caller: the journal row, the reservation's
``paid`` and the ledger credit commit together or not at all. Alerts are
returned, not sent — a Telegram call inside a money transaction would hold the
row locks for a network round trip.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime
from decimal import Decimal
from typing import Any, Final, Literal

from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession

from yupay.core.ids import new_id
from yupay.core.logging import get_logger
from yupay.modules.merchants.deposit import credit_deposit
from yupay.modules.p2p.models import P2PCard, P2PIncoming, P2PReservation
from yupay.modules.p2p.parsing import ParsedNotification, parse_humo
from yupay.modules.p2p.settings import load_settings

log = get_logger("yupay.p2p.intake")
_ZERO: Final = Decimal("0")

Status = Literal["dropped", "duplicate", "matched", "unmatched", "ignored"]


@dataclass
class IntakeResult:
    status: Status
    reservation_number: str | None = None
    alerts: list[tuple[str, str]] = field(default_factory=list)


def _humo_message(update: dict[str, Any], humo_id: int | None) -> dict[str, Any] | None:
    msg = update.get("business_message")
    if not isinstance(msg, dict) or humo_id is None:
        return None
    sender = (msg.get("from") or {}).get("id")
    chat = (msg.get("chat") or {}).get("id")
    if sender != humo_id or chat != humo_id or msg.get("forward_origin"):
        return None
    return msg


async def _chain_ok(db: AsyncSession, p: ParsedNotification) -> bool | None:
    if p.kind not in ("credit", "debit") or p.balance_after is None or p.amount is None:
        return None
    prev = await db.scalar(
        select(P2PIncoming)
        .where(P2PIncoming.card_last4 == p.card_last4, P2PIncoming.balance_after.is_not(None))
        .order_by(P2PIncoming.bank_time.desc(), P2PIncoming.received_at.desc())
        .limit(1)
    )
    if prev is None or prev.balance_after is None:
        return None
    signed = p.amount if p.kind == "credit" else -p.amount
    return prev.balance_after + signed == p.balance_after


async def _payable(db: AsyncSession, p: ParsedNotification, received_at: datetime) -> P2PReservation | None:
    if p.kind != "credit" or p.amount is None or p.amount != p.amount.to_integral_value():
        return None
    card = await db.scalar(select(P2PCard).where(P2PCard.pan_last4 == p.card_last4))
    if card is None:
        return None
    paid_at = p.bank_time or received_at
    return await db.scalar(
        select(P2PReservation)
        .where(
            P2PReservation.card_id == card.id,
            P2PReservation.amount_uzs == int(p.amount),
            P2PReservation.status.in_(("pending", "expired")),
            P2PReservation.holds_amount.is_(True),
            P2PReservation.expires_at >= paid_at,
        )
        .order_by(P2PReservation.created_at)
        .limit(1)
        .with_for_update()
    )


async def ingest_update(db: AsyncSession, update: dict[str, Any], *, received_at: datetime) -> IntakeResult:
    """Journal one Telegram update and credit the reservation it pays, if any."""
    settings = await load_settings(db)
    msg = _humo_message(update, settings.humo_bot_user_id)
    if msg is None:
        return IntakeResult("dropped")

    text = str(msg.get("text") or "")
    parsed = parse_humo(text)
    row = P2PIncoming(
        id=new_id(), business_connection_id=str(msg.get("business_connection_id") or ""),
        telegram_message_id=int(msg["message_id"]), kind=parsed.kind, amount_uzs=parsed.amount,
        source_text=(parsed.source or "")[:128] or None, card_last4=parsed.card_last4,
        bank_time=parsed.bank_time, balance_after=parsed.balance_after, raw_text=text,
        result="ignored", received_at=received_at,
    )
    row.chain_ok = await _chain_ok(db, parsed)
    try:
        async with db.begin_nested():
            db.add(row)
            await db.flush()
    except IntegrityError:
        return IntakeResult("duplicate")

    result = IntakeResult("ignored")
    if parsed.kind == "unparsed":
        result.alerts.append(("p2p_unparsed", f"P2P: не удалось разобрать уведомление HUMO (id {row.telegram_message_id})"))
    if row.chain_ok is False:
        result.alerts.append(("p2p_chain_break", f"P2P: разрыв цепочки балансов по *{row.card_last4} — возможно пропущено уведомление"))

    if parsed.kind == "credit":
        reservation = await _payable(db, parsed, received_at)
        if reservation is None or reservation.merchant_id is None:
            row.result = "unmatched"
            result.status = "unmatched"
            log.info("p2p.unmatched", amount=str(parsed.amount), card_last4=parsed.card_last4)
        else:
            await credit_deposit(
                db, merchant_id=reservation.merchant_id, amount=reservation.amount_usd,
                actor="p2p", idempotency_key=f"p2p:{reservation.id}", order_id=None,
                note=f"P2P · {reservation.number}",
            )
            reservation.status = "paid"
            reservation.holds_amount = False
            reservation.closed_at = received_at
            reservation.quarantine_until = None
            reservation.incoming_id = row.id
            row.result, row.reservation_id = "matched", reservation.id
            result.status, result.reservation_number = "matched", reservation.number
            log.info("p2p.matched", number=reservation.number, amount_uzs=reservation.amount_uzs)
    await db.flush()
    return result


__all__ = ["IntakeResult", "ingest_update"]
```

"""Telegram Business updates for @depositlistenerbot → P2P intake (spec §5.4).

Authenticity first: Telegram echoes the ``secret_token`` we gave ``setWebhook``
in ``X-Telegram-Bot-Api-Secret-Token``. It is compared before a byte of the body
is read, and an unset secret refuses everything — an unconfigured receiver
that accepted all would look like it worked.
"""

from __future__ import annotations

import hmac
import json
from typing import Annotated, Any

from fastapi import APIRouter, Depends, Header, HTTPException, Request, status
from sqlalchemy.ext.asyncio import AsyncSession

from yupay.api.v1.deps import db_session
from yupay.core.clock import now
from yupay.core.config import get_settings
from yupay.core.logging import get_logger
from yupay.modules.notifications.alerts import send_admin_alert
from yupay.modules.p2p.intake import ingest_update

router = APIRouter(prefix="/webhooks/telegram", tags=["webhooks:telegram"])
log = get_logger("yupay.webhooks.telegram_p2p")
MAX_BODY_BYTES = 64 * 1024


@router.post("/p2p", status_code=status.HTTP_200_OK, summary="HUMO notifications via Telegram Business")
async def receive_p2p_update(
    request: Request,
    db: Annotated[AsyncSession, Depends(db_session)],
    secret: Annotated[str, Header(alias="X-Telegram-Bot-Api-Secret-Token")] = "",
) -> dict[str, Any]:
    expected = get_settings().p2p_webhook_secret
    if not expected or not hmac.compare_digest(secret.encode(), expected.encode()):
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED)
    raw = await request.body()
    if len(raw) > MAX_BODY_BYTES:
        raise HTTPException(status_code=status.HTTP_413_CONTENT_TOO_LARGE)
    try:
        update = json.loads(raw)
    except ValueError:
        return {"ok": True}  # Telegram's own body; a retry would be the same bytes.
    if not isinstance(update, dict):
        return {"ok": True}
    result = await ingest_update(db, update, received_at=now())
    await db.commit()
    for kind, text in result.alerts:
        await send_admin_alert(text, kind=kind)
    return {"ok": True}

```python
"""P2P housekeeping every 30 s: expire overdue top-ups, end quarantine, notice silence.

Correctness does not depend on this tick — the webhook and the cabinet read
both treat an overdue ``pending`` as expired — so a missed tick only delays
the release of a quarantined amount. The silence alert is the one thing only
this job can see: reservations expiring while @HUMOcardbot has said nothing
for hours means the Business bot is disconnected, not that nobody paid.
"""

from __future__ import annotations

from datetime import datetime, timedelta
from typing import Final

from apscheduler.schedulers.asyncio import AsyncIOScheduler
from sqlalchemy import func, select

from yupay.core.clock import now
from yupay.core.db import get_session_factory
from yupay.core.logging import get_logger
from yupay.core.redis import get_redis
from yupay.modules.notifications.alerts import send_admin_alert
from yupay.modules.p2p.models import P2PIncoming
from yupay.modules.p2p.reservations import sweep

log = get_logger("yupay.scheduler.p2p_sweep")
_JOB_ID: Final = "p2p_sweep"
_INTERVAL_SECONDS: Final = 30
SILENCE: Final = timedelta(hours=6)
_ALERT_KEY: Final = "p2p:silence-alert"
_ALERT_TTL_SECONDS: Final = 3600


def silence_alert_due(last_incoming_at: datetime | None, expired_now: int, now_: datetime) -> bool:
    """Whether expiring reservations coincide with a silent HUMO feed."""
    if expired_now <= 0:
        return False
    return last_incoming_at is None or now_ - last_incoming_at > SILENCE


async def run_p2p_sweep() -> None:
    """One tick."""
    t = now()
    async with get_session_factory()() as db:
        result = await sweep(db, now_=t)
        last = await db.scalar(select(func.max(P2PIncoming.received_at)))
        await db.commit()
    if result.expired or result.released:
        log.info("p2p_sweep.tick", expired=result.expired, released=result.released)
    if silence_alert_due(last, result.expired, t):
        redis = get_redis()
        if await redis.set(_ALERT_KEY, "1", nx=True, ex=_ALERT_TTL_SECONDS):
            await send_admin_alert(
                "P2P: резервы истекают, а от HUMO нет уведомлений больше 6 часов — проверьте бота",
                kind="p2p_silence",
            )


def register(scheduler: AsyncIOScheduler) -> None:
    """Attach the job. Safe to call once at startup."""
    scheduler.add_job(run_p2p_sweep, trigger="interval", seconds=_INTERVAL_SECONDS,
                      id=_JOB_ID, replace_existing=True, max_instances=1, coalesce=True)
    log.info("p2p_sweep.registered", interval_seconds=_INTERVAL_SECONDS)


__all__ = ["SILENCE", "register", "run_p2p_sweep", "silence_alert_due"]
```

        fx_rate=str(r.fx_rate), created_at=r.created_at, expires_at=r.expires_at,
        closed_at=r.closed_at, card=card,

    enabled = admits(await load_settings(db), merchant.id)
    rate: str | None = None

    await db.commit()  # guarded_usd_rate may have written an fx_snapshots row

```ts
import type { P2PDeposit } from "./types";

/** Whole seconds until `expiresAt`, never negative. */
export function secondsLeft(expiresAt: string, nowMs: number): number {
  return Math.max(0, Math.floor((Date.parse(expiresAt) - nowMs) / 1000));
}

/** "50 001" in the cabinet's locale — soʻm have no minor unit on screen. */
export function formatSom(amount: number, locale: string): string {
  return new Intl.NumberFormat(locale, { maximumFractionDigits: 0 }).format(amount);
}

/**
 * The USD the deposit will get, rounded DOWN to cents — the server's rule, so the
 * preview never promises a cent the credit will not carry. Integer maths on
 * cents keeps floats out of money.
 */
export function usdPreview(amountUzs: number, rate: string | null): string | null {
  if (!rate || !(amountUzs > 0)) return null;
  const r = Number(rate);
  if (!(r > 0)) return null;
  const cents = Math.floor((amountUzs * 100) / r);
  return `${String(Math.floor(cents / 100))}.${String(cents % 100).padStart(2, "0")}`;
}

export type Phase = "amount" | "details" | "paid" | "expired" | "cancelled";

/** Which screen a deposit belongs on. */
export function phase(d: P2PDeposit | null): Phase {
  if (d === null) return "amount";
  switch (d.status) {
    case "pending":
      return "details";
    case "paid":
      return "paid";
    case "expired":
      return "expired";
    case "cancelled":
      return "cancelled";
  }
}
```
