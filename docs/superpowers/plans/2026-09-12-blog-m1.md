# Blog — M1: Schema, Sanitize, Admin CRUD, Public GET

> **For agentic workers:** implement task-by-task. Steps use checkbox (`- [ ]`)
> syntax. One logical commit per task. Do not start M2 (storefront) in this
> plan.

**Goal:** An admin can create, translate, publish and archive a blog post
bound to a catalogue brand. The public API serves published translations.
There is no storefront UI yet (M2). The admin editor in M1 is a textarea
plus a sanitized preview — TipTap is M3.

**Architecture:** New domain module `apps/api/src/yupay/modules/blog/` per
`AGENTS.md` §4. Catalogue is referenced by FK only; prices are not joined.
HTML is persisted only after `blog.sanitize`.

**Tech stack:** Python 3.12, FastAPI, SQLAlchemy 2 async, Alembic, Pydantic v2;
admin Vite SPA for the textarea form.

**Spec:** `docs/superpowers/specs/2026-09-12-blog-design.md`

## Global constraints

- mypy --strict, ruff `line-length=100`, Google docstrings, no `Any` without
  a justifying comment. File soft limit 400 LOC.
- Money is not in this module. Coverage gate is the repo default (≥ 80%),
  **sanitize ≥ 95%** (it is the XSS control).
- Admin chrome: ru/en/uz in the same PR.
- Mutations: `Idempotency-Key`. Public GETs are keyless reads.
- Never log `body_html` (UGC-sized). Log `post_id`, `kind`, `status`.
- `pnpm exec prettier --check` on every TS/JSON/MD touch. Never `next build`
  on the host.
- Do not commit `Makefile` / `scripts/seed*` leftovers or `.agents/`.
